# 单页 A4 PDF：各模块建议字数（软上限）

当前 PDF 为 **A4**、`buildResumePdfHtml.mjs` 中正文约 **11pt**、行高约 **1.55**，左右留白与 `max-width: 800px` 折行后，**可印刷区域大约 45～50 个汉字宽度/行、纵向约 30～38 行纯正文**（还要扣掉标题、姓名行、各 `h2` 与卡片标题条）。  
因此 **「单页塞满所有模块」时，全篇汉字当量在约 900～1200 字较稳**；再多容易分页或挤版，需缩小字号或整体 `scale`（尚未在流水线里默认开启）。

下列为 **按模块单独填写时** 的经验软上限（**汉字 + 标点**，英文/数字可按「约 0.6 个汉字宽」折算）。**不是代码硬截断**，超出仍生成 PDF，仅分页风险升高。前端可做 `maxlength` 或保存前提示。

| 模块 | 建议上限（约） | 备注 |
|------|------------------|------|
| 页眉区（姓名 + 性别/手机/邮箱 + 意向行） | 姓名≤20 字；意向行 `title_line`≤60 字 | 头像占位约 72×96pt |
| **自我评价** `self_evaluation` | **280 字** | 富文本 strip 后计 |
| **教育背景** 每条 `education_entries[].html` | **单条 180 字**；多条时总量建议 **≤360 字** | 含学校/专业/时间等合并进一条 HTML 时 |
| **在校经历** 每条 `campus_experience_entries[].html` | **单条 220 字** | |
| **工作经历** 每条 `work_experience_entries[].html` | **单条 220 字** | |
| **项目经历** 每条 | 描述 **≤320 字**；要点/高亮合并 **≤200 字**；`tech_stack` 每项算 **约 12 字** | 旧 `projects[]` 结构同理 |
| **专业技能** `skills_items` 展开或 `skills` 列表 | **≤260 字** | 含「技能名（掌握度）」 |

**组合原则**：若六大块都写满，建议 **总量控制在 1000 字左右**；若某几块为空（前端不传），可把字数让给其它块，但总篇幅仍建议不超过上表「单页总预算」。

## 后续对接（预留）

- 前端字段改名/增删时，同步 **`resume_segments.cpp`**（C++ 拆段）与 **`extractSegments.mjs` + `buildResumePdfHtml.mjs`**（Node 高亮与排版），保持 **segment `id` 一致**。
- 若产品要求 **强制单页**：可在 `renderPdf.mjs` 增加 `page.pdf({ scale: … })` 或 CSS 整体缩小，并与上述字数表一起回归。
