# Major Skill：会计学

## 核心考察维度
1. **会计基础**：会计要素、借贷记账、权责发生制、收入确认、费用匹配
2. **报表理解**：三大报表勾稽、关键科目变动解释
3. **实务意识**：凭证/单据、对账、内控、审计配合
4. **职业素养**：细致、保密、合规、抗压

## 常见问题池
### A. 概念与准则理解
- 权责发生制 vs 收付实现制区别？各自适用场景？
- 你如何理解“收入确认”？哪些业务容易产生争议？

### B. 报表与分析
- 三大报表之间如何勾稽？举例说明“利润高但现金流差”的原因。
- 毛利率异常波动你怎么排查？从哪些科目/业务入手？

### C. 内控与合规
- 你理解的关键内控点有哪些？（采购-付款、销售-收款、存货、费用报销）
- 发现单据不齐全但业务确实发生，你会怎么处理？

## 追问模板
- 请给一个具体例子：**科目/凭证/影响报表哪一行**？
- 你如何确保准确性？复核/对账/抽查怎么做？
