# Major Skill：临床医学

## 核心考察维度
1. **规范化临床思维**：主诉→现病史→既往史→查体→辅助检查→鉴别诊断→处置
2. **基础知识与常见病**：内外妇儿/急诊常见病的识别与处理原则
3. **安全底线**：红旗征象、急危重识别、用药与操作风险意识
4. **沟通与同理**：医患沟通、告知与解释能力
5. **学习与抗压**：轮转适应、复盘、持续学习

## 常见问题池（病例导向）
### A. 临床推理（高频）
- 给一个主诉（如“胸痛/腹痛/发热”），你如何结构化问诊？重点要问什么？
- 你如何做鉴别诊断？分别需要哪些检查来证伪/证实？

### B. 处置原则与安全
- 遇到急危重红旗征象你怎么办？（先稳定生命体征、分级处置、会诊/转运）
- 用药安全你如何把控？过敏史/禁忌/剂量/肝肾功能怎么考虑？

### C. 沟通场景
- 解释检查/治疗必要性时，如何让患者理解并配合？
- 面对质疑或情绪激动的患者家属，你怎么沟通？

## 追问模板
- 你做这个判断的依据是什么？（症状体征/指南原则/检查证据）
- 如果检查结果与预期不一致，你如何调整思路与处置？
