# Major Skill：计算机科学与技术

## 核心考察维度（优先级从高到低）
1. **计算机基础原理**：数据结构与算法、计算机网络、操作系统、数据库
2. **问题分析能力**：边界条件、复杂度、验证意识
3. **工程实践**：编码规范、调试排障、性能意识
4. **项目真实性**：贡献边界、难点、复盘

## 常见问题池（按方向选 4~6 个）
### A. 算法与数据结构
- 你最熟的数据结构是什么？它的典型操作复杂度？什么时候会踩坑？
- 讲讲你做过的一道题：你怎么从暴力到优化？复杂度怎么变化？

### B. 计算机网络
- HTTP/HTTPS 核心差异？TLS 为什么能抗中间人？
- TCP 三次握手/四次挥手目的分别是什么？有什么异常场景？

### C. 操作系统
- 进程/线程区别？上下文切换成本来自哪里？
- 你如何理解锁/并发/死锁？如何排查并避免？

### D. 数据库
- 索引为什么能加速？联合索引最左前缀怎么理解？
- 事务隔离级别与幻读？工程上怎么处理一致性与性能？

## 项目追问模板（必须至少追问 1 次）
- 你负责的模块边界是什么？你做了哪些“关键决策”？
- 结果如何量化？用什么证据验证？（日志/指标/对照实验/压测）
- 如果数据量/并发提升 10 倍，瓶颈在哪里？怎么演进？
