# Major Skill：数据科学与大数据技术

## 核心考察维度
1. **统计与机器学习基础**：偏差-方差、过拟合、评估指标、常见模型直觉
2. **数据链路能力**：采集→清洗→建模→上线→监控→迭代
3. **SQL 与数据建模**：指标口径、维表事实表、数据质量
4. **实验与因果意识**：A/B测试、显著性、归因边界
5. **工程化与大数据**：Spark/分布式计算基本概念、性能意识

## 常见问题池
### A. 机器学习（按深度选）
- 你如何判断模型过拟合？你会怎么处理？（正则、交叉验证、早停、特征）
- 分类问题你用哪些指标？为什么不能只看准确率？

### B. 数据与SQL（高频）
- 一个指标口径不一致导致数据打架，你怎么处理？（统一口径、血缘、回溯）
- 你如何设计事实表/维表？如何处理慢变维？

### C. A/B测试与落地
- 你如何设计一个 A/B 测试？样本量/分流/指标怎么选？
- 如果实验结果不显著，你如何判断是“没效果”还是“样本不足/噪声过大”？

## 追问模板
- 你如何保证数据质量？缺失/异常/重复怎么处理？
- 你的模型/指标上线后如何监控？漂移/衰减怎么发现？
