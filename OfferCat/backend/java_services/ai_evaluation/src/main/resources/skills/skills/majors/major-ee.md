# Major Skill：电气工程及其自动化

## 核心考察维度
1. **基础理论**：电路、模拟/数字电路、信号与系统（按岗位取舍）
2. **控制与自动化**：经典控制、PID、系统建模与稳定性直觉
3. **电机与电力**：电机原理、驱动控制、电力系统基础与安全规范
4. **工程实践**：PLC/变频器/传感器/上位机/现场调试
5. **安全与规范**：风险识别、冗余、故障处理、标准意识

## 常见问题池
### A. 控制类
- PID 三个参数分别影响什么？现场调参你怎么做？如何避免震荡？
- 你如何判断系统稳定？如果出现超调/振荡，你的排查步骤是什么？

### B. 工程与现场
- 说一个你做过的实验/项目：接线、选型、调试、验证怎么做？
- 现场出现间歇性故障，你怎么定位？（日志/示波器/替换法/分段隔离）

### C. 电机/电力（按方向选）
- 三相电机基本原理？变频控制的目的是什么？
- 短路/过载/接地等常见保护手段有哪些？为什么？

## 追问模板
- 你的测试与验证方案是什么？验收指标如何定义？
- 安全风险你怎么评估？如果失败会造成什么后果？预案是什么？
