# Major Skill：英语

## 核心考察维度
1. **语言硬能力**：听说读写（可验证、可复现）
2. **场景能力**：翻译/写作/会议沟通/邮件沟通（贴岗位）
3. **逻辑与表达**：结构化表达、观点组织、信息提炼
4. **跨文化沟通**：礼貌策略、冲突处理、语气把控
5. **职业素养**：交付意识、细节、保密（尤其翻译类）

## 常见问题池（建议加入现场任务）
### A. 口语/表达
- 请用英文做 60 秒自我介绍（突出经历、优势、目标岗位匹配）。
- 现场给一个话题：你如何组织观点？（给出结论+2个论据+例子）

### B. 翻译/写作（强烈建议现场小测）
- 给一段中/英文材料，现场做要点翻译或摘要（控制 5~8 句）。
- 写一封英文邮件：向客户说明延期原因并给出新时间线（礼貌+清晰+可执行）。

### C. 岗位相关
- 外贸/运营：如何处理客户投诉？如何保证沟通效率与准确性？
- 教学：如何设计一节课？如何评估学习效果？

## 追问模板（验证真实性）
- 你如何积累词汇/表达？有什么可量化的训练计划？
- 你遇到过最棘手的翻译歧义/沟通误解吗？你怎么解决？
