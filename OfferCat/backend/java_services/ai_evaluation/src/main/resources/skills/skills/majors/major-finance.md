# Major Skill：金融学

## 核心考察维度
1. **金融基础**：利率/久期、风险收益、货币时间价值、衍生品基本概念
2. **市场理解**：宏观变量与资产价格、行业与公司基本面
3. **分析能力**：数据与逻辑、假设与验证、结构化表达
4. **风控意识**：风险识别、合规底线、情景分析
5. **岗位匹配**：投研/销售/风控/运营等的核心能力差异

## 常见问题池
### A. 基础题
- 利率上升对债券价格有什么影响？为什么？
- 你如何理解“风险溢价”？在投资决策中怎么用？

### B. 案例题（高频）
- 给你一个行业/公司，你如何快速做投资判断？（商业模式、竞争格局、财务、估值、催化、风险）
- 市场大幅波动时，你如何控制回撤？（仓位、止损、分散、对冲）

### C. 风控与合规
- 你如何识别“高收益陷阱”？你会看哪些信号？
- 如果业务希望绕开流程提升效率，你怎么处理？

## 追问模板
- 你的结论基于哪些数据？如果关键假设不成立会怎样？
- 你能说清楚“最大的风险是什么、如何监控、如何止损”吗？
