# Major Skill：法学

## 核心考察维度
1. **法律基础**：民法/公司法/劳动法/合同法相关体系化理解
2. **合同审查能力**：风险点识别、条款改写、谈判要点
3. **合规与风控**：底线意识、证据意识、留痕意识
4. **表达与逻辑**：结构化陈述、论证链条、结论可落地
5. **业务理解**：能把法律建议翻译成业务可执行动作

## 常见问题池
### A. 合同审查（高频）
- 你拿到一份合作协议，第一步看什么？（主体、权责、违约、争议解决）
- 请举 3 个你最常见的风险条款，并说出改写建议。

### B. 劳动与合规
- 劳动争议中企业常见风险点有哪些？你会怎么提前预防？
- 数据/隐私合规你怎么理解？遇到业务强推你怎么处理？

### C. 案例分析（看思维）
- 给你一个纠纷案例，请用“事实—规则—适用—结论”组织回答。

## 追问模板
- 你的结论依据是什么条款/原则？有没有反例或例外？
- 给业务方建议时，你会如何平衡风险与业务收益？
