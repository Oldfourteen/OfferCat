# Major Skill：市场营销

## 核心考察维度
1. **用户洞察**：目标用户是谁？痛点/场景/决策链路
2. **增长与渠道**：渠道选择逻辑、投放与转化漏斗、ROI意识
3. **内容与品牌**：定位、差异化、传播策略、口径一致性
4. **数据与复盘**：指标体系、A/B测试思维、复盘闭环
5. **沟通协同**：与产品/销售/设计协作推进

## 常见问题池（按岗位方向选）
### A. 方案题（最常用）
- 给你一个新产品/活动，你怎么从 0 到 1 做推广？（目标、用户、渠道、预算、指标）
- 如果活动效果不达标，你如何定位问题？（漏斗拆解：曝光-点击-转化-留存）

### B. 数据题（必须追问）
- 你做过最成功的一次活动/投放，核心指标是什么？提升了多少？怎么归因？
- 你如何做 A/B 测试？样本量不够时怎么决策？

### C. 用户与内容
- 你如何做用户画像？如何验证画像不是“拍脑袋”？
- 写一条能促转化的文案，你会怎么组织？（卖点、证明、行动号召）

## 追问模板（防“空话”）
- 你的目标指标是什么？为什么选这个指标？有没有对照组？
- 预算有限时你先投哪里？放弃哪里？依据是什么？
