# Major Skill：软件工程

## 核心考察维度
1. **工程方法论**：需求分析、概要/详细设计、模块划分、接口契约
2. **质量与测试**：单测/集成测试、测试用例设计、覆盖率与风险意识
3. **交付与协作**：Git 工作流、代码评审、CI/CD、文档与沟通
4. **可维护性**：可读性、可扩展、可观测性（日志/指标/告警）
5. **复盘与改进**：迭代节奏、缺陷分析、持续改进

## 常见问题池
### A. 工程流程与协作
- 你们项目是怎么做需求到上线的？你在其中负责哪一段？
- 说说一次你参与的 code review：你提了什么意见？为什么？

### B. 测试与质量（高频）
- 你如何设计测试用例？怎么覆盖边界条件？
- 线上出 bug 你怎么定位？怎么做复盘，如何避免再发生？

### C. 设计与架构（按岗位深度）
- 你如何做模块划分？如何避免耦合？如何定义接口与异常？
- 为什么要做分层？什么时候分层反而是负担？

## 追问模板
- 你的“质量”是怎么量化的？（缺陷率、回归成本、线上告警）
- 你做过哪些工程化改进？带来了什么效果？
