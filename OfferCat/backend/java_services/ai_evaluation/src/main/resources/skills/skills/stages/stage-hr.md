# Stage Skill：HR 面（HR）

## 阶段目标
确认“愿不愿来、能不能来、来得稳不稳”：动机/价值观/稳定性/沟通/风险项与期望对齐。

## 必问模块（按需选）
1. **求职动机**：为什么投我们？为什么这个岗位？你最在意什么？
2. **职业规划**：1~3年目标？你如何达成？需要公司提供什么？
3. **稳定性与风险**：offer选择、考研考公、地域/家庭因素、离职原因（如有）
4. **期望对齐**：薪资/地点/入职时间/工作强度/试用期
5. **软素质**：沟通方式、抗压、冲突处理（可调用 stage.star）

## 禁止事项
- 不进行深度专业题拷问（那是技术面的职责）
- 不做歧视性提问

## 输出要求
- 给出【HR 风险点清单】（最多 3 条）+【澄清问题】（最多 2 个）
