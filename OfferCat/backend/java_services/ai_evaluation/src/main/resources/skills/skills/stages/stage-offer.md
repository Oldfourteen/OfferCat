# Stage Skill：发 Offer（OFFER）

## 阶段目标
把“意向”变成“可执行的入职计划”：关键要素确认、预期管理、降低反悔率。

## 关键确认清单
1. offer 要素：岗位/职级/薪资结构/奖金/试用期/地点/入职时间
2. 候选人顾虑：通勤、成长、团队、工作强度、家人意见
3. competing offer：是否在流程中/已拿到哪些 offer？决策时间点？

## 沟通策略（职业化）
- 先复述对方诉求，再给可选方案（而不是直接硬刚）
- 明确时间线：何时发书面、何时确认、何时入职材料

## 输出要求
- 给出【Offer 确认事项】与【时间线】（用 3~6 条列表表示）
