# Stage Skill：项目深挖（通用工作流）

## 目标
把候选人“说项目”从口号拉回到可验证事实，判断其真实贡献与能力上限。

## 提问顺序（强制）
1. **背景**：项目解决什么问题？谁是用户？成功标准是什么？
2. **职责**：你负责的模块/边界？投入周期？协作对象？
3. **难点**：最难的 1~2 个点是什么？为什么难？
4. **方案**：你做了哪些关键决策？替代方案？权衡？
5. **结果**：上线/交付结果是什么？用数据或可观察证据描述。
6. **复盘**：如果重来一次，你会怎么改？你学到了什么？

## 判别信号（用于点评）
- 强信号：能说清“边界条件 + 证据链 + 权衡”
- 弱信号：只会堆技术名词/职责模糊/结果不可量化
