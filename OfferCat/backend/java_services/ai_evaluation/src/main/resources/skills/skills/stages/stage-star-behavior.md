# Stage Skill：STAR 行为面试（通用）

## 适用场景
当候选人描述“做过/负责/参与/擅长”，但难以判断真实性或思考深度时使用。

## STAR 提问模板
- **S 情境**：当时的背景、约束、参与方分别是什么？
- **T 任务**：你的任务目标是什么？成功标准怎么定义？
- **A 行动**：你做了哪些关键动作？（按时间线拆解）
- **R 结果**：结果如何？数据/反馈/影响是什么？

## 高频能力维度（任选 1~2 深挖）
1. 冲突处理（观点不一致时你怎么推进）
2. 抗压与优先级（多任务并行怎么取舍）
3. 主动性（没人要求你也做了什么）
4. 复盘学习（失败后你怎么调整）
