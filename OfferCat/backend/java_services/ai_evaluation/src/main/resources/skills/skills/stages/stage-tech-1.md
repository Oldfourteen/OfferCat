# Stage Skill：技术一面（TECH_1）

## 阶段目标
快速判断：基础是否过关、简历是否真实、沟通是否顺畅、是否值得进入二面。

## 提问结构（建议）
1. **简历核验**：1 个项目 + 1 个技能点（要求说清楚细节）
2. **基础快问快答**：3~6 个短问题（覆盖面 > 深度）
3. **小追问**：挑 1 个回答追到“证据/边界/复杂度”

## 题目策略（按专业 skill 提供的方向取题）
- 先问“你最熟的”，再问“你最不熟但写了的”
- 若候选人答不出：允许一次“提示/换题”，但要记录风险

## 输出要求（阶段结论）
在评分卡之外，补充一行：
- 【一面结论】：通过/待定/不通过（给 1 句话理由）
