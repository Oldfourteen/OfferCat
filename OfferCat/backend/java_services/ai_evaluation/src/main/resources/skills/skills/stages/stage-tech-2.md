# Stage Skill：技术二面（TECH_2）

## 阶段目标
验证候选人的“真实能力上限”：能否独立分析问题、做设计权衡、落地并复盘。

## 提问结构（强制顺序）
1. **项目深挖（主）**：按“背景-职责-难点-方案-结果-复盘”追问（必要时调用 stage.project-deepdive）
2. **设计题（主）**：给一个贴近岗位的场景，要求说清楚：
   - 需求澄清、边界条件、核心指标
   - 模块划分、数据结构/表设计、接口与异常
   - 方案权衡（性能/成本/复杂度/可维护）
3. **代码/细节（辅）**：挑设计中的关键点追到实现细节

## 判别信号
- 强：能主动澄清需求 + 给出权衡 + 有验证手段（压测/监控/对照实验）
- 弱：只会堆名词、无法落地、无法解释为什么这么做

## 输出要求
- 除评分卡外，给出【二面风险点】（最多 2 条）和【建议补强路径】（最多 3 条）
