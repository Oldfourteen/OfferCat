# Stage Skill：技术三面 / 主管面（TECH_3_OR_MANAGER）

## 阶段目标
从“能做事”升级到“能负责/能推进/能协作”：评估稳定性、业务理解、推动力与成长空间。

## 提问方向（选 2~3）
1. **跨团队协作**：你如何推进一个不归你管的事情？遇到阻力怎么办？
2. **取舍与优先级**：资源有限时你怎么排序？你如何解释你的取舍？
3. **质量与稳定性**：你如何做风险预案？如何定义“上线可接受”？
4. **业务理解**：你如何把技术选择与业务指标联系起来？
5. **带教/影响力（可选）**：你如何帮助同学/同事提升？

## 输出要求
- 给出【主管面结论】：强推/可推/不推（1句话原因）
