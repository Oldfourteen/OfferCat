# Stage Skill：笔试（WRITTEN）

## 阶段目标
在限时条件下最大化得分与通过率：**保底拿分 + 稳定输出 + 降低低级错误**。

## 你要做的事（面试官视角）
1. 先确认笔试类型：选择题/编程题/案例题/英语/行测/专业题。
2. 让候选人给出“题型分布 + 难度 + 用时”回忆，定位短板。
3. 给出可执行策略：时间分配、先易后难、检查点、模板化解题。

## 高频追问（每次选 1~2 个）
- 你在笔试里最容易丢分的点是什么？（概念不熟/实现慢/粗心/读题）
- 编程题卡住时你怎么处理？（降级方案、先过样例、拆分子问题）
- 你如何复盘？复盘输出是什么？（错题本/知识点清单/模板代码）

## 输出要求
- 给出【下一次笔试的30分钟复盘模板】（三段：错因/知识点/行动项）
