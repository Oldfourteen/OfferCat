# `static/galaxy-h5/assets/galaxy.css` 改动说明

## 一、说明目的

本文档用于记录 `static/galaxy-h5/assets/galaxy.css` 中与“专业星系”页面顶部栏相关的样式改动，方便后续排查、交接和回溯。

需要特别注意：

- `static/galaxy-h5/assets/galaxy.css` 是星系 H5 页面当前落库的静态样式产物
- 如果后续重新从上游源码构建并覆盖 `static/galaxy-h5`，这些修改有可能被重新生成的产物覆盖
- 因此本文档记录的是“当前静态包中的实际改动结果”，不代表上游源码已经同步修改

## 二、本次改动文件

- 文件：`static/galaxy-h5/assets/galaxy.css`

## 三、本次改动范围

本次改动集中在“专业星系”页面顶部栏，也就是以下这一组样式：

- `.custom-nav[data-v-500dcac5]`
- `.nav-btn[data-v-500dcac5]`
- `.nav-btn-img[data-v-500dcac5]`
- `.nav-title[data-v-500dcac5]`
- `.nav-right[data-v-500dcac5]`
- `.nav-spacer[data-v-500dcac5]`

本次没有调整页面主内容结构，也没有改动星系图本身的交互逻辑，主要是顶部栏的视觉和尺寸优化。

## 四、改动内容明细

### 1. 顶部栏高度调整为 `60px`

顶部栏高度由原先较小的尺寸调整为：

```css
height: calc(60px + var(--gx-safe-top));
```

这样处理的目的：

- 让标题区域更舒展
- 让返回按钮与标题的垂直视觉更平衡
- 在手机设备上点击区域更友好
- 保留 `safe-top`，兼容刘海屏和安全区域

### 2. 顶部占位高度同步调整

顶部栏下方用于顶开内容区域的占位同步改为：

```css
height: calc(68px + var(--gx-safe-top));
```

这样做是为了保证：

- 内容不会被 fixed 顶栏遮挡
- 顶栏增高后，正文起始位置仍然正确

### 3. 返回按钮尺寸调整

返回按钮与右侧占位区域同步调整为：

```css
width: 40px;
height: 40px;
```

对应影响：

- `.nav-btn[data-v-500dcac5]`
- `.nav-right[data-v-500dcac5]`

调整目的：

- 保证在 `60px` 顶栏高度下比例协调
- 提高返回按钮点击热区
- 避免按钮过小导致视觉空洞

### 4. 返回图标尺寸调整

返回箭头图标尺寸改为：

```css
width: 20px;
height: 20px;
```

调整目的：

- 和 `40px` 按钮尺寸匹配
- 保证图标在白底按钮中清晰可见
- 避免按钮放大后图标显得过小

### 5. 标题字号调整

标题字号调整为：

```css
font-size: 17px;
```

当前标题仍保留：

- `font-weight: 700`
- `color: #fff`
- `text-shadow: 0 1px 3px rgba(0,0,0,.15)`

调整目的：

- 在顶栏增高后让标题视觉重心更稳定
- 保证“专业星系”在移动端仍然清晰

### 6. 顶部栏背景改为蓝色磨砂半透明渐变

当前顶部栏背景由较早的纯紫色渐变，调整为带磨砂感的蓝色半透明渐变：

```css
background: linear-gradient(180deg, rgba(93,143,223,.82) 0%, rgba(154,205,250,.72) 48%, rgba(155,204,249,.62) 100%);
```

颜色走向是：

- 顶部偏深蓝
- 中间过渡到 `#9ACDFA` 体系
- 底部过渡到更浅的蓝色

这样做的目的：

- 让顶部栏和当前浅蓝色页面氛围更统一
- 弱化原先偏紫的视觉感受
- 提升页面整体轻盈感和现代感

### 7. 新增磨砂半透明效果

顶部栏新增：

```css
backdrop-filter: blur(16px);
-webkit-backdrop-filter: blur(16px);
```

作用：

- 让顶部栏呈现玻璃感 / 毛玻璃效果
- 保留背景颜色的层次感
- 让 fixed 顶栏更有“悬浮在内容上方”的感觉

之所以同时写两条，是为了兼顾不同 WebView / 浏览器内核对前缀属性的支持。

### 8. 新增顶部栏底边与轻阴影

新增样式：

```css
border-bottom: 1px solid rgba(255,255,255,.28);
box-shadow: 0 6px 20px rgba(93,143,223,.14);
```

作用：

- 用底边增强顶部栏与内容区之间的层次边界
- 用轻阴影强化悬浮感
- 避免半透明背景在浅色内容上边界不清

## 五、当前顶部栏最终效果总结

当前 `galaxy.css` 中顶部栏可以概括为：

- 高度：`60px + safe-top`
- 风格：蓝色竖向渐变
- 质感：磨砂半透明
- 按钮：白色圆形返回按钮
- 标题：白色 `17px` 粗体文本

整体视觉方向是：

- 比原始紫色顶栏更轻
- 比纯白顶栏更稳
- 比完全实色块更有层次

## 六、为什么改在这里

当前仓库里，能直接定位并立即生效的顶部栏样式就在：

- `static/galaxy-h5/assets/galaxy.css`

这是当前静态包实际生效的样式文件，因此对页面的顶部栏视觉调整，直接改这里可以立刻验证效果。

但需要注意：

- 这里属于构建产物层
- 如果上游星系源码重新 build 并覆盖静态包，这里的修改可能丢失

因此，这类改动适合：

- 快速验证视觉方案
- 临时落地样式调整
- 记录当前线上/当前仓库生效效果

不适合长期只停留在静态产物层，不同步到真正源码。

## 七、后续维护建议

如果后续要长期保留当前顶部栏效果，建议：

1. 找到星系页面真正的源码文件
2. 将相同样式同步回源码
3. 重新构建生成新的 `galaxy.css`
4. 用新的构建产物替换当前静态包

否则，后续一旦重新构建星系页面，当前直接改在 `static/galaxy-h5/assets/galaxy.css` 里的样式仍有被覆盖的风险。

## 八、一句话结论

本次对 `static/galaxy-h5/assets/galaxy.css` 的改动，核心是把“专业星系”页面顶部栏调整为 `60px` 高度，并改成蓝色磨砂半透明的顶部栏视觉，以提升页面整体层次感和移动端可用性。
